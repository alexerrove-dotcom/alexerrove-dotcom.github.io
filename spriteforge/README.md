# SpriteForge RU — генерация спрайтов на устройстве

**Сайт:** https://alexerrove-dotcom.github.io/spriteforge/

Независимый русскоязычный инструмент создания персонажей, анимаций и спрайт-листов на GitHub Pages. Не связан со SpriteGen.ai.

## 1. Автономный режим — без серверов

Основной пункт «Автономный генератор · без сети». Это наш собственный **процедурный графический движок**, написанный на JavaScript Canvas 2D. **Это не обученная нейросеть и не полноценный аналог современных моделей text-to-image.** Он анализирует русские/английские ключевые слова, собирает персонажа из многослойных фигур и создаёт покадровые движения из изменяющихся положений частей тела.

Поддерживаемые типы: лис, волк, кот, собака, кролик, медведь, белка, мышь, лягушка, птица, дракон, робот, зомби, скелет, слайм, рыцарь, волшебник, пират, ниндзя, космонавт, эльф, человек. Поддержка одежды и предметов ограничена перечисленными правилами: шарф, плащ, сумка, броня, очки, шляпа, рога, крылья, рогатка, меч, посох, арбалет, лук, топор, щит, фонарь и др. Неизвестные слова могут игнорироваться.

Есть действия (бег, ходьба, прыжок, атака, боль, смерть, магия, полёт), число кадров и направление. Стили отличаются палитрой и растеризацией, а не полностью независимыми художественными моделями.

Экспорт: PNG (спрайт-лист с прозрачным фоном), ZIP (отдельные PNG-кадры и JSON), JSON атлас. Чтобы открывать сайт повторно **без интернета**, нужно хотя бы один раз посетить его онлайн: service worker сохранит HTML/JS файлы. Браузер может позже удалить кэш.

## 2. Локальная нейросеть WebGPU — экспериментальная

Дополнительный пункт «Нейросеть WebGPU · на устройстве» использует открытую предобученную модель **SD-Turbo** и библиотеку **web-txt2img 0.3.1**, собранную в собственные файлы GitHub Pages. Вычисления проходят **в браузере на видеокарте пользователя**, без удалённого GPU и API для инференса.

**ВАЖНО:** веса SD-Turbo **скачиваются один раз с Hugging Face**, затем могут кэшироваться локально. Требуется несколько гигабайт свободного места, совместимый WebGPU-браузер и большой объём памяти. Следовательно, режим использует внешний **файловый сервер при первой загрузке модели**, но не удалённый сервер генерации. На телефонах и слабых ПК может не работать.

Модель создаёт **одно изображение героя** по запросу; последующие кадры — локальные трансформации этого изображения, а не нейросетевая генерация новых поз. Русские слова преобразуются в ограниченные английские шаблоны, а не переводятся полноценно. Нельзя обещать качество или полное соответствие функциям оригинального SpriteGen.ai. Генерация весами модели на GPU ещё требует практического тестирования.

## 3. Дополнительные инструменты

- Пиксель-редактор Canvas: карандаш, ластик, зеркальное рисование, PNG.
- Конвертер GIF в листы PNG (браузеры с ImageDecoder).
- Сборщик PNG/JPEG/WebP в PNG атлас с JSON.
- Библиотека последних результатов только в памяти вкладки, без аккаунтов.

## Код и тесты

- index.html — пользовательский интерфейс.
- local-generator.js — собственный офлайновый движок генерации и ZIP-экспорта.
- neural-engine.js — генерация через WebGPU и трансформация кадров.
- webgpu-src/ — исходники подключения web-txt2img и сборка.
- webgpu/ — собранный WebGPU-рантайм.
- sw.js и manifest.json — поддержка PWA и автономной работы.
- test_frontend.mjs — тест с отключённой сетью и проверка ZIP.
- test_webgpu.mjs — тест запуска локального браузерного WebGPU worker (без весов).
- backend/ и hf-space/ — сохранённые прототипы внешнего API; **опубликованный интерфейс их больше не использует**.

CI: https://github.com/alexerrove-dotcom/alexerrove-dotcom.github.io/actions

Локальная проверка: в корне репозитория запустить Python HTTP-сервер с портом 8000 и открыть http://localhost:8000/spriteforge/.

WebGPU билд: перейти в папку spriteforge/webgpu-src, выполнить npm install, затем npm run build.

## Лицензии

Собственная часть SpriteForge написана независимо. web-txt2img распространяется под MIT, предобученные веса имеют собственную лицензию и условия использования. Чужой закрытый код и веса SpriteGen.ai не использовались.
