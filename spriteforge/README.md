# SpriteForge RU — генерация спрайтов на устройстве

**Сайт:** https://alexerrove-dotcom.github.io/spriteforge/

Независимый русскоязычный инструмент создания персонажей, анимаций и спрайт-листов на GitHub Pages. Не связан со SpriteGen.ai.

## Обновление v4 — геометрия лица и анимационные суставы

Перед переработкой изучены официальные примеры SpriteGen: https://spritegen.ai/gallery/knight-walk-sprite-sheet/, https://spritegen.ai/gallery/knight-run-sprite-sheet/, https://spritegen.ai/gallery/knight-jump-sprite-sheet/ и https://spritegen.ai/gallery/fox-idle-sprite-sheet/. В работе использованы **общие принципы анимации**, не графика и не код авторов.

- **Face Studio V4 (face-v4.js):** отдельные геометрические схемы морд животных и человеческих/роботизированных лиц; меньшее соотношение глаз к голове; устойчивые точки глаз, носа, щёк, рта; мимика и моргание.
- **Pose Solver V4 (pose-v4.js):** у каждой ноги две кости и вычисленная коленка, фаза опоры и переноса, фиксация высоты стоящей стопы; шаг бега длиннее шага ходьбы.
- **Поза прыжка:** приседание, отталкивание, подтягивание ног и приземление. Сам спрайт **не перемещается по высоте внутри ячейки**: перемещением в сцене управляет физика Godot/другого движка.
- **Поза атаки:** подготовка, замах, удар и возврат. Оружие крепится к кисти персонажа. Ранее поверх него рисовалась ещё одна кисть из декоративного слоя, теперь это устранено.
- **Стабильный спрайт:** одинаковый размер кадра/кроп для всех действий, постоянный seed и палитра; слой деталей синхронизирован с основной позой.
- **Графические пропорции:** хвост лисы и волка приведён к более умеренному размеру.
- В браузерном тесте дополнительно проверяются точка опоры, вычисление колена, разные стадии атаки и неподвижность корня спрайта по высоте при прыжке.

В отличие от генератора SpriteGen, использующего удалённый набор моделей, наш основной автономный режим остаётся процедурным (Canvas 2D). Качество и разнообразие не могут быть идентичными нейросетевым выходам.

## Обновление автономного генератора v3

Ранее персонаж собирался из нескольких простых геометрических фигур. В v3 новый пайплайн включает:

- **Design Parser v3:** выделение породы персонажа, цветов шерсти/кожи, шарфа, одежды, брони; подробности вроде шрамов, полосок, пятен, масок и гербов. Это обработка ключевых слов и зависимостей в предложении, а не полноценный язык модели.
- **Art Studio v3:** многослойные цветовые переходы, тени, локальные узоры/фактура, детали костюма, швы, болты и украшения, цветовая вариативность, материалы по типу персонажа. Это собственная Canvas 2D отрисовка поверх базовой анатомии.
- **Вид сверху:** отдельная отрисовка сверху с поворотами в восемь направлений. Изометрия пока только стилизует проекцию и не гарантирует полноценный объём.
- **Вариант внешности:** числовой seed сохраняет особенности при повторном создании; кнопка «Новая вариация» меняет детали без изменения текста описания.
- **Полный пакет анимаций:** одним запросом рисуются idle, walk, run, jump, attack, death. В каждом действии используется одно и то же описание и seed. Пакеты поддерживают несколько направлений с ограничением до 192 кадров; для больших пакетов доступны размеры не выше 128 px.
- **Экспорт:** PNG лист, JSON координаты и ZIP с разложенными по действиям и направлениям отдельными PNG. В правой панели можно выбрать анимацию и направление для просмотра без повторной генерации.
- **Без сервера:** всё это работает в браузере после первого открытия сайта. Проверяется в GitHub Actions с полностью отключённой сетью, включая ZIP и полный пакет.

Качество графики нельзя объективно измерить формулировкой «в 15 раз»: не существует единой численной шкалы качества игрового спрайта. Рост детализации и возможностей не равен 15-кратному росту художественного качества. Движок всё ещё ограничен подготовленными типами деталей, формами и ключевыми словами; он не заменяет мощную обученную text-to-image модель.

## 1. Автономный режим — без серверов

Основной пункт «Автономный генератор · без сети». Это наш собственный **процедурный графический движок**, написанный на JavaScript Canvas 2D. **Это не обученная нейросеть и не полноценный аналог современных моделей text-to-image.** Он анализирует русские/английские ключевые слова, собирает персонажа из многослойных фигур и создаёт покадровые движения из изменяющихся положений частей тела.

Поддерживаемые типы: лис, волк, кот, собака, кролик, медведь, белка, мышь, лягушка, птица, дракон, робот, зомби, скелет, слайм, рыцарь, волшебник, пират, ниндзя, космонавт, эльф, человек. Поддержка одежды и предметов ограничена перечисленными правилами: шарф, плащ, сумка, броня, очки, шляпа, рога, крылья, рогатка, меч, посох, арбалет, лук, топор, щит, фонарь и др. Неизвестные слова могут игнорироваться.

Есть действия (бег, ходьба, прыжок, атака, боль, смерть, магия, полёт), число кадров и направление. Стили отличаются палитрой и растеризацией, а не полностью независимыми художественными моделями.

Экспорт: PNG (спрайт-лист с прозрачным фоном), ZIP (отдельные PNG-кадры и JSON), JSON атлас. Чтобы открывать сайт повторно **без интернета**, нужно хотя бы один раз посетить его онлайн: service worker сохранит HTML/JS файлы. Браузер может позже удалить кэш.

## 2. Локальная нейросеть WebGPU — экспериментальная

Дополнительный пункт «Нейросеть WebGPU · на устройстве» использует открытую предобученную модель **SD-Turbo** и библиотеку **web-txt2img 0.3.1**, собранную в собственные файлы GitHub Pages. Вычисления проходят **в браузере на видеокарте пользователя**, без удалённого GPU и API для инференса.

**ВАЖНО:** веса SD-Turbo **скачиваются один раз с Hugging Face**, затем могут кэшироваться локально. Требуется несколько гигабайт свободного места, совместимый WebGPU-браузер и большой объём памяти. Следовательно, режим использует внешний **файловый сервер при первой загрузке модели**, но не удалённый сервер генерации. На телефонах и слабых ПК может не работать.

Модель создаёт **одно изображение героя** по запросу; последующие кадры — локальные трансформации этого изображения, а не нейросетевая генерация новых поз. Русские слова преобразуются в ограниченные английские шаблоны, а не переводятся полноценно. Нельзя обещать качество или полное соответствие функциям оригинального SpriteGen.ai. Генерация весами модели на GPU ещё требует практического тестирования.

## 3. Дополнительные инструменты

- Пиксель-редактор Canvas: карандаш, ластик, зеркальное рисование, PNG.
- Конвертер GIF в листы PNG (браузеры с ImageDecoder).
- Сборщик PNG/JPEG/WebP в PNG атлас с JSON.
- Библиотека последних результатов только в памяти вкладки, без аккаунтов.

## Код и тесты

- index.html — пользовательский интерфейс.
- local-generator.js — собственный офлайновый движок анимаций, атласов и ZIP.
- designer-v3.js — разбор русских описаний и семантическое разделение цветов.
- face-v4.js — новый независимый модуль пропорций лица и мимики.
- pose-v4.js — собственная система фаз ходьбы, бега, прыжка, атаки и IK для ног.
- illustrator-v2.js — базовые рисованные формы и анимационный скелет.
- illustrator-v3.js — новый визуальный слой деталей, текстуры и отдельный ракурс сверху.
- neural-engine.js — генерация через WebGPU и трансформация кадров.
- webgpu-src/ — исходники подключения web-txt2img и сборка.
- webgpu/ — собранный WebGPU-рантайм.
- sw.js и manifest.json — поддержка PWA и автономной работы.
- test_frontend.mjs — тест с отключённой сетью и проверка ZIP.
- test_webgpu.mjs — тест запуска локального браузерного WebGPU worker (без весов).
- backend/ и hf-space/ — сохранённые прототипы внешнего API; **опубликованный интерфейс их больше не использует**.

CI: https://github.com/alexerrove-dotcom/alexerrove-dotcom.github.io/actions

Локальная проверка: в корне репозитория запустить Python HTTP-сервер с портом 8000 и открыть http://localhost:8000/spriteforge/.

WebGPU билд: перейти в папку spriteforge/webgpu-src, выполнить npm install, затем npm run build.

## Лицензии

Собственная часть SpriteForge написана независимо. web-txt2img распространяется под MIT, предобученные веса имеют собственную лицензию и условия использования. Чужой закрытый код и веса SpriteGen.ai не использовались.
